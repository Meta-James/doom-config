* Why this file exists
:PROPERTIES:
:ID:       cheat-why
:END:

Phase 7 ([[id:roadmap-phase-7][roadmap]]) began from an audit finding that read
badly: roughly 35 enabled modules had no configuration, and 55 installed
packages were never named in =config.org=. The obvious conclusion — that a large
amount of capability sat unwired — turned out to be wrong.

Doom configures nearly all of it at *module* level. Absence from =config.org=
usually means nothing was needed, not that nothing was done. The genuine gap was
never configuration; it was knowing what is already there. That makes this
document, rather than several hundred lines of new elisp, the main deliverable
of the phase. See [[id:adr-module-flag-sweep][ADR-036]] for the sweep that came
out of the same audit.

*Scope.* This lists capability that exists and tends to go unused. It is not a
complete keymap dump — =SPC h b b= (=describe-bindings=) and =SPC= followed by a
pause (which-key) already do that better, and a hand-maintained copy of them
would rot. What is here is the subset worth *knowing about* rather than
discovering by accident.

*Evidence standard.* Every binding below was read out of module source under
=~/.config/emacs/sources/doom+/modules/= and is cited by file and line, the same
standard [[id:ai-keybindings][keybindings.org]] holds itself to. None of it is
recalled from memory or from upstream documentation, both of which drift from
what a given Doom checkout actually does.

Two path abbreviations used throughout:
- =+evil-bindings.el= = =modules/config/default/+evil-bindings.el=
- =evil/config.el= = =modules/editor/evil/config.el=

* Things that exist but have no key yet
:PROPERTIES:
:ID:       cheat-unbound
:END:

Recorded so they are not rediscovered from scratch:

- =treesit-fold= — installed, and usable for the first time now that Phase 7
  installed tree-sitter grammars. Doom's =:editor fold= dispatches the =z= keys
  across hideshow, vimish-fold and treesit-fold, so it is partly reachable
  already; no dedicated binding was added.
- =consult-dir=, =consult-yasnippet=, =consult-flycheck=, =wgrep= — all
  configured by the vertico module (=completion/vertico/config.el:196-320=). The
  =embark-export= → =wgrep= loop (act on a search result set, export it to a
  buffer, edit every match, save) is the highest-value unused workflow in this
  config, and =embark-act= is on =SPC a=.
- =crdt= (=:tools collab +tunnel=) and =:app irc= — enabled, no configuration, no
  use to date.

* Maintaining this file
:PROPERTIES:
:ID:       cheat-maintenance
:END:

Line numbers drift when Doom is upgraded. When a citation stops matching, re-read
the source rather than patching the number from memory — the point of this file
is that every row was verified once, and a guessed correction quietly destroys
that property. =SPC h b b= remains the authority for what is bound *right now*.
