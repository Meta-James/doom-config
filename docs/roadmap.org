* Phase 7 — Capability activation (in progress)
:PROPERTIES:
:ID:       roadmap-phase-7
:END:

Scoped 2026-08-30 after an audit that asked a different question from
[[id:adr-module-sweep-non-lang][ADR-029]]'s. ADR-029 asked which modules were
off; this asks which modules are *on and doing nothing*.

The measurement: the Emacs half of =config.org= is about 590 code lines, over
half of it in four areas (ghostel, Vulpea, mu4e, Python/LSP). Roughly 35 enabled
modules and flags have zero configuration, and 55 installed packages are never
named in =config.org=. Three different problems were tangled together in that
number, and the phase separates them:

1. *Inert* — enabled, and unable to work as configured. Tree-sitter was the
   headline: every =+tree-sitter= flag was set and not one grammar was installed.
2. *Unconfigured but usable* — Doom binds avy, embark, vundo, git-timemachine,
   quickrun and the =:tools lookup= stack regardless. The gap is knowing the
   keys, so the fix is a document, not elisp.
3. *Genuinely unwired* — packages that ship with an enabled module and do
   nothing without configuration: =gptel-magit=, =ob-gptel=, =org-modern=,
   =org-noter=, =org-download=, =dape=, =citar=, =consult-dir=, =wgrep=.
